# 🛍️ eCommerce Frontend UI Template (TailwindCSS)

A modern and complete eCommerce frontend UI built with TailwindCSS.  
Designed with a clean, responsive layout and structured components to help you build faster and launch quickly.

## 🚀 Features
- Multi-page UI (Home, Shop, Product Detail, Cart, Auth)
- Modern & clean design (conversion-focused)
- Fully responsive (mobile, tablet, desktop)
- Built with TailwindCSS
- Reusable components & well-structured folders
- Easy to customize and extend
